# AI calls go through one provider interface, and every tier gets every feature

The app stops being Claude-only and stops gating features by tier. Every AI call goes through one `AiClient` interface with two implementations: Anthropic's Messages API (today's `ClaudeClient`) and an OpenAI-compatible client that covers OpenRouter and any user-supplied endpoint, which is how someone reaches their own Ollama server. Which provider, key and model a call uses is resolved per feature in the order user setting, then instance setting, then the app default ("Let NouriLoop choose"). First-class Ollama or OpenAI screens wait until users ask; four providers at launch would be a model-quality support matrix forever. Because a user's model can be worse at reading meal photos than ours, vision analysis requires a model that passes a built-in benchmark of five reference meals, and a failing model is reported as the user's model failing, not as NouriLoop being wrong. Decided by John on 2026-10-11 (Transformation Plan D12, §3F) and 2026-10-12 (App Development Plan Q1–Q6).

The tiers become self-host (no billing, set by `APP_HOSTING_MODE=self`), hosted BYOK ($2/month, the user's own key, no allowance) and hosted Full ($13.50/month, our key and model). All three are full-featured: `SubscriptionTier::hasFeature()` stops gating, except that hosted SMS is Full-only, because Twilio's fixed fees are a cost a user's AI key doesn't cover; self-hosters can bring their own Twilio. Prices cover cost with no margin: Full is priced from John's own usage (about 120 meal analyses a month plus check-ins, insights and help), and the LLC absorbs fixed hosting as a portfolio cost. When a Full user uses up the allowance, AI features pause until the month resets and a one-time $1.75 top-up adds 60 analyses for the current month; overage is never billed.

The allowance keeps ADR 0001's mixed counting (deleting a meal still refunds its slot). Separately, every AI call is written to a cost record (provider, model, input and output tokens, estimated cost), so prices can be checked against what calls actually cost; that record is for measurement and does not change what the allowance counts.
